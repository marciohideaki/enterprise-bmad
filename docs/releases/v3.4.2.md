# HSEOS v3.4.2 — Stabilization release

## Scope and authorization

This patch publishes the verified repository consolidation from
[PR #171](https://github.com/marciohideaki/enterprise-hseos/pull/171).
The repository owner explicitly requested closure of the stabilization release
in the active delivery session on 2026-09-07.

- Breaking changes: none; no state schema migration or new governance activation.
- Risk: High under the release-control rubric because the patch includes security
  dependency remediation. Distribution is limited to release artifacts; production
  service deployment and its operational monitoring gates are separate activities.
- Rollout: build a prerelease, verify its checksums and isolated installation,
  then promote the same immutable artifact to a stable GitHub release.
- Historical prototypes and recovered private runtime data are not part of the release.

## Changes

- Portable emitted agent filenames, with collision rejection and stale-output checks.
- Private temporary directories for supervised execution, preserving restrictive
  permissions, sandbox boundaries, binary verification and cleanup.
- Reproducible dependency installation without tracked generated cache metadata.
- Remediated transitive dependencies and normalized repository formatting.
- Portable hardlink rejection fixtures and PostgreSQL integration in the runtime CI matrix.
- An auditable recovery inventory and restored immutable federated dependencies.

## Validation

The consolidation passed the full runtime suite, PostgreSQL integration (15 tests),
compiled-artifact verification (222 checks), formatting, lint, schema validation,
dependency audit and federated composition. Release preparation reruns the enforced
gates and the protected PR matrix on Node.js 20 and 22. The tag pipeline rebuilds
and tests the exact release revision and produces a package, CycloneDX SBOM and
SHA256SUMS. Stable promotion follows downloaded-asset verification and an isolated
CLI installation smoke test. The release records the authoritative workflow results.

## Installation

Download `hseos-3.4.2.tgz`, `hseos-3.4.2.cdx.json` and `SHA256SUMS` from this GitHub
release. Verify both files before installing:

```bash
sha256sum -c SHA256SUMS
npm install --global ./hseos-3.4.2.tgz
hseos --version
```

## Rollback

Download the existing v3.4.1 release assets into a separate directory, verify its
SHA256SUMS, and reinstall its package. This restores the prior CLI package without
changing project-owned configuration, state or governance sources.

```bash
sha256sum -c SHA256SUMS
npm install --global ./hseos-3.4.1.tgz
hseos --version
```

Before stable promotion, exercise the previous package in an isolated installation.
Production consumers should apply their own staged rollout and monitoring policy.
